VideoGrab - installed
=====================

Everything lives in THIS folder (default: C:\VideoArji),
including VideoGrab.exe. Nothing is scattered elsewhere.

Where your downloads go
-----------------------
    <this folder>\
        VideoGrab.exe   the program
        downloads\      your downloaded videos
        ffmpeg.exe      auto-downloaded on first run (~80MB, once)

The exact download path is always shown on the web page.

Tips
----
- Start: double-click VideoGrab.exe, then open
  http://localhost:8080 in your browser
  (a browser tab usually opens by itself).
- Uninstall: Start menu -> VideoGrab -> Uninstall VideoGrab
  (your downloads\ folder is kept).
