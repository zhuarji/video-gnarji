VideoGrab - installed
=====================

Everything was installed into THIS folder, including
VideoGrab.exe. Nothing is scattered elsewhere.

Where your downloads go
-----------------------
    <this folder>\videoarji\
        downloads\      your downloaded videos
        ffmpeg.exe      auto-downloaded on first run (~80MB, once)

The exact download path is always shown on the web page.

Tips
----
- Start: double-click VideoGrab.exe, then open
  http://localhost:8080 in your browser
  (a browser tab usually opens by itself).
- If you installed into C:\Program Files and downloads
  fail with "permission denied", move the app to a normal
  folder (Desktop, D:\VideoGrab ... ) - the program needs
  to write next to itself.
- Uninstall: Start menu -> VideoGrab -> Uninstall VideoGrab
  (your videoarji folder with downloaded videos is kept).
